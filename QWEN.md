## Qwen Added Memories
- CostPilot is a cloud cost optimization platform with a FastAPI backend (Python 3.12+) and React/TypeScript frontend using Ant Design. It supports multi-cloud (AWS, Azure, GCP) cost tracking, resource discovery, recommendations, pool-based org hierarchy, expense tracking, rules engine, advanced RBAC with ABAC, notifications, scheduler, user management, and data export. The tech stack includes PostgreSQL (async), MongoDB, Redis for caching, JWT auth with httpOnly cookies, and Docker Compose for orchestration. Key security features: encrypted cloud credentials, rate limiting, input validation, timeout middleware, audit logging, token blacklisting, session binding to IP/fingerprint. The backend has 14 enterprise feature stubs (chargeback, allocation, audit logging, approvals, forecasting, commitments, FX/tax, anomaly detection, maturity assessment, collaboration, connectors, export, platform health). Backend lives in `backend/app/`, frontend in `frontend/src/`. Database uses SQLAlchemy async with connection pooling (pool_size=20, max_overflow=40). MongoDB and Redis also have connection pooling. The project has documented security audit findings in AUDIT.md and a feature backlog in BACKLOG.md.
